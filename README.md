## Featured Projects

### Glass Ops

A complete job management platform designed for the glazing repair industry.

Glass Ops combines an ASP.NET Core web application with .NET MAUI mobile applications and provides functionality for managing customers, contracts, jobs, surveying, fitting, field operations, media and business workflows.

**Technologies include:**

- C# / .NET
- ASP.NET Core MVC
- .NET MAUI
- Entity Framework Core
- SQL Server
- REST APIs
- ASP.NET Core Identity
- HTML / CSS / JavaScript
- Multi-tenant architecture

A demonstration system is available through the portfolio.

### Craig's Casino

A web-based casino project developed as an exploration of interactive application and game development.

The project includes browser-based games alongside Unity development, demonstrating C#, JavaScript, animation, game logic and web integration.
